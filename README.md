# slime-mold-image
NetLogo slime mold network code modifier to accept and run the simulation on images. Version actually used for the paper is in CompleteRun.nlogo
Images must follow the color coding already present in netlogo: red for walls and yellow for food, if nuclei are placed directly on the image they must be white, they can also be placed later after the image is loaded.
Data tables related to the paper 'But They Built Roads', forthcoming, are also listed here, downloaded from WITS database in 2026 to allow for computation of an Africa region and a GCC region (separate from the MENA and SSA regions of the World Bank).
Simulation results were combined to create a composite image of the 'average' network predicted over multiple runs using the python code composites.py.
